Principio de Arpen Arpen funciona principalmente de forma local. No vende datos personales, no incluye publicidad y no crea perfiles publicitarios.

1. Datos que Arpen trata

Según las funciones que elijas utilizar, Arpen puede tratar:

  • Metadatos de música y video, como título, artista, álbum, duración y tipo de archivo.
  • Playlists, orden de reproducción, favoritos, ajustes, perfiles de audio, mapas del modo ritmo, progreso, Arps, logros y configuraciones visuales.
  • Letras importadas, creadas o sincronizadas por el usuario.
  • Fondos, imágenes, portadas personalizadas, archivos de música y videos únicamente cuando el usuario decide incluirlos en un respaldo o transferencia.
  • Nombre, correo electrónico, identificador de Google y foto de perfil disponible mediante Google cuando el usuario inicia sesión voluntariamente para usar Google Drive.
  • Un identificador técnico y nombre del dispositivo durante una conexión directa mediante Arpen Link.

2. Biblioteca local

Arpen solicita permisos para leer archivos multimedia únicamente para mostrar y reproducir la biblioteca local autorizada por el usuario. Los archivos permanecen en el dispositivo, salvo que el usuario elija expresamente incluirlos en un respaldo o transferencia.

3. Google Drive y respaldos opcionales

El inicio de sesión con Google es opcional. Si autorizas Google Drive, Arpen puede crear, consultar, descargar o restaurar respaldos dentro de tu propia cuenta de Google Drive.

Los respaldos solo incluyen los elementos seleccionados por el usuario: datos de Arpen, playlists, letras, mapas, perfiles, fondos, imágenes, archivos de música o videos. Aurevia no opera un servidor propio para almacenar estos respaldos.

Puedes revocar el acceso desde tu cuenta de Google y eliminar los respaldos directamente desde Google Drive.

4. Arpen Link

Arpen Link permite transferir paquetes elegidos por el usuario entre dispositivos conectados a una red local. Durante una conexión se intercambian los datos técnicos necesarios para identificar los dispositivos y el contenido seleccionado para transferir.

Esta función no utiliza servidores de Aurevia y requiere la intervención explícita del usuario. Se recomienda utilizar redes locales confiables.

5. Letras y servicios externos

Cuando utilizas las funciones relacionadas con letras, Arpen puede abrir o consultar LRCLIB u otro servicio externo elegido por ti. Para realizar una búsqueda, se pueden enviar datos como título, artista, álbum o duración de una canción al servicio correspondiente.

El uso de servicios externos se rige también por sus propias políticas de privacidad.

6. Micrófono

El micrófono solo se utiliza si activas expresamente una función reactiva o de calibración. Arpen no lo utiliza para publicidad, vigilancia ni para enviar grabaciones a servidores de Aurevia.

7. Compartición y seguridad

Arpen solo comparte datos en los siguientes casos elegidos por el usuario:

  • Con Google Drive, al crear, consultar o restaurar un respaldo.
  • Con otro dispositivo, al iniciar una transferencia mediante Arpen Link.
  • Con un servicio externo de letras, al realizar una búsqueda o abrir dicho servicio.

Las comunicaciones con Google Drive y servicios web compatibles usan las conexiones seguras proporcionadas por dichos servicios. Aurevia no vende información personal ni incorpora redes publicitarias.

8. Conservación y eliminación

  • Los datos locales pueden eliminarse desde Arpen, al borrar los datos de la aplicación o al desinstalarla.
  • Los respaldos de Google Drive pueden eliminarse desde Google Drive.
  • Los paquetes de Arpen Link y respaldos locales permanecen bajo control del usuario en la ubicación elegida.
  • Aurevia no conserva una base de datos propia con la biblioteca, archivos multimedia o respaldos de los usuarios.

9. Público y actualizaciones

Arpen está orientada a usuarios de 13 años o más y no está diseñada específicamente para menores de 13 años.

Esta política puede actualizarse cuando cambien las funciones de Arpen o las obligaciones aplicables. La fecha de actualización aparecerá al inicio de esta página.
