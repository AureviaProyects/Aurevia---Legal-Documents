Política de privacidad de Arpen

Última actualización: 26 de noviembre de 2026

Esta Política de privacidad explica cómo Aurevia trata los datos al usar Arpen, aplicación para Android con identificador de paquete com.aurevia.arpen.

Arpen está diseñado para funcionar principalmente de forma local. No vende datos personales, no incluye publicidad ni usa datos para crear perfiles publicitarios.

1. Datos que Arpen trata

Según las funciones que elijas utilizar, Arpen puede tratar:

  • Metadatos de música y video presentes en tu dispositivo, como título, artista, álbum, duración y tipo de archivo.
  • Playlists, orden de reproducción, favoritos, ajustes, perfiles de audio, mapas del modo ritmo, progreso, Arps, logros y configuraciones visuales.
  • Letras importadas, creadas o sincronizadas por el usuario.
  • Fondos, imágenes, portadas personalizadas, archivos de música y videos únicamente cuando el usuario decide incluirlos en una transferencia o respaldo.
  • Nombre, correo electrónico, identificador de Google y foto de perfil disponible mediante Google cuando el usuario inicia sesión voluntariamente para usar Google Drive.
  • Un identificador técnico del dispositivo y nombre del dispositivo durante una conexión directa mediante Arpen Link.

2. Uso local de la biblioteca

Arpen solicita permisos para leer archivos multimedia únicamente para mostrar y reproducir la biblioteca local que el usuario autorice. Estos archivos permanecen en el dispositivo salvo que el usuario elija expresamente incluirlos en un respaldo o transferencia.

3. Google Drive y respaldos opcionales

El inicio de sesión con Google es opcional. Si eliges autorizar Google Drive, Arpen puede crear, consultar, descargar o restaurar respaldos dentro de tu propia cuenta de Google Drive. Los respaldos pueden incluir únicamente los elementos que selecciones: datos de Arpen, playlists, letras, mapas, perfiles, fondos, imágenes, archivos de música o videos.

Arpen usa el permiso de Google Drive limitado a los archivos creados o abiertos por Arpen. Aurevia no opera un servidor propio para almacenar esos respaldos. Puedes revocar el acceso desde tu cuenta de Google y eliminar los respaldos directamente desde Google Drive.

4. Arpen Link

Arpen Link permite transferir paquetes que el usuario elige entre dispositivos conectados a una red local. Durante una conexión se intercambian datos técnicos necesarios para identificar los dispositivos y los archivos o datos seleccionados para la transferencia. Esta función no usa servidores de Aurevia y requiere la intervención explícita del usuario.

5. Letras y servicios externos

Cuando el usuario utiliza las funciones relacionadas con letras, Arpen puede abrir o consultar LRCLIB u otro servicio externo elegido por el usuario. Para realizar una búsqueda, se pueden enviar datos como título, artista, álbum o duración de la canción al servicio correspondiente. El uso de esos servicios se rige también por sus propias políticas de privacidad.

6. Micrófono

El micrófono solo se utiliza si el usuario activa expresamente una función reactiva o de calibración. Arpen no utiliza el micrófono para publicidad, vigilancia ni para enviar grabaciones a servidores de Aurevia.

7. Compartición de datos

Arpen solo comparte datos en los siguientes casos controlados por el usuario:

  • Con Google Drive, cuando el usuario autoriza y crea, consulta o restaura un respaldo.
  • Con otro dispositivo, cuando el usuario inicia una transferencia mediante Arpen Link.
  • Con un servicio externo de letras, cuando el usuario realiza una búsqueda o abre dicho servicio.

Aurevia no vende información personal, no incorpora redes publicitarias y no comparte datos para publicidad personalizada.

8. Conservación y eliminación

  • Los datos locales pueden eliminarse desde las opciones de Arpen, al borrar los datos de la aplicación o al desinstalarla.
  • Los respaldos de Google Drive pueden eliminarse desde Google Drive.
  • Los paquetes de Arpen Link y respaldos locales permanecen bajo control del usuario en la ubicación que este haya elegido.
  • Aurevia no conserva una base de datos propia con la biblioteca, archivos multimedia o respaldos de los usuarios.

9. Seguridad

Las comunicaciones con Google Drive y servicios web compatibles usan conexiones seguras proporcionadas por dichos servicios. Las transferencias de Arpen Link ocurren directamente dentro de la red local seleccionada por el usuario; se recomienda usar redes confiables.

10. Público

Arpen está orientada a usuarios de 13 años o más. No está diseñada específicamente para menores de 13 años.

11. Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones de Arpen o las obligaciones aplicables. La fecha de actualización se mostrará al inicio de esta página.
